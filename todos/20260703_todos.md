### 전술턴

#### 전술턴 진입 판정 (endTurn() 내부)
1.  `endTurn()` 실행 순서:
    - `_processAgendas()`: 의안 처리 및 실행
    - `_income()`: 수입 계산 (`인구 × 세율 × 산업도 × 10`), 함대 유지비 차감
    - `_supply()`: 함대 보급 상태 갱신 (아군 성계 +10%, 적 성계 -5%)
    - `_fleetMove()`: 함대 이동 처리 (`moveTurnsLeft--`) → 도착 시 위치 갱신 및 **적 감지**
    - `_morale()`: 사기 증감
    - `_construct()`: 건설 진행 (`turnsLeft--` → 완성 시 수치 반영)
    - `_events()`: 랜덤 이벤트 발생
    - `_ai()`: AI 세력 행동 처리
    - 게임 내 시간 증가 (day → month → year)
    - `turn` 증가
    - `_victory()`: 한 세력이 전체 성계의 70% 이상 점유 시 게임 종료

2.  전략턴 종료 후, 전술턴의 실행 조건을 확인하고 실행 조건이 충족된 경우 전술턴을 실행한다.
    a. 아국의 함대가 적국의 성계에 존재할 경우, 혹은 적국의 함대가 아국의 성계에 존재할 경우
    b. 국적이 다른 함대가 lane에서 조우할 경우
    위의 조건 중 하나 이상이 존재할 경우 `_pendingBattle` 객체를 생성하고, 성계 ID 순서대로 전술턴을 진행한다.
    c. 플레이어 캐릭터가 해당 지역에 존재하지 않을 경우 confirm으로 `#{성계}에서 교전이 발생하였습니다.\n상세 전투를 보시겠어요?` 를 노출한다.
    - [네] 버튼: 전술턴 2번 항목(전술턴 수행)으로 이동
    - [아니오] 버튼: 해당 전투를 자동 처리 후 결과만 노출
    d. 전술턴을 모두 수행한 후 `턴의 종료` 로직을 수행한다.

    3-3. 우측 캐릭터 정보 패널(`CharInfoPanel.vue`)은 함대(편대) 정보 패널로 교체.

        - 지휘관 인물 정보(이름, 전투력) 표시

#### 전술 전투 흐름 (`tacticalStore.js`)

4.  전술 전투 초기화 (`initBattle(context)`):
    - `context`: `{ attackerFleet, attackerFaction, defenderFleets, targetSystemId, opType }`
    - 편대(Squadron) 생성 규칙:
      - 함선 ≥ 12,000 → 3개 편대
      - 함선 ≥ 6,000 → 2개 편대
      - 함선 < 6,000 → 1개 편대
    - 공격측은 우측(x = MAP_W-2), 방어측은 좌측(x = 1) 배치
    - 초기 사기 80, 진형 `DOUBLE_COL`

5.  전술 턴은 3페이즈로 진행:

    **Phase 1: 플레이어 턴 (phase = 'player')**
    - `selectUnit(id)`: 유닛 선택 → 이동 가능 칸(`_calcMovable`) / 공격 가능 칸(`_calcAttackable`) 계산
    - `moveUnit(tx, ty)`: 이동 (`moved = true`), Manhattan 거리 ≤ 진형 속도
    - `attackUnit(targetId)`: 공격 (`attacked = true`) → `_combat()` 호출
    - `changeFormation(unitId, formId)`: 진형 변경 → 이동/공격 범위 재계산
    - 모든 유닛 행동 완료 또는 [턴종료] 버튼 → Phase 2 진입

    **Phase 2: AI 턴 (phase = 'ai')**
    - `_aiTurn()` 자동 실행:
      - 20% 확률로 진형 변경
      - 가장 가까운 플레이어 유닛 탐색 (Manhattan 거리)
      - 사거리 내 → 전투 수행
      - 사거리 외 → 최단 이동 후 재확인
      - 함선 ≤ 0 또는 사기 ≤ 10 → 유닛 제거
    - AI 턴 완료 → `_checkVictory()` 호출

    **Phase 3: 결과 (phase = 'result')**
    - 승리 조건 (`_checkVictory()`):
      - 적 유닛 전멸 → 공격측 승리
      - 플레이어 유닛 전멸 → 방어측 승리
    - 결과 표시: 손실 함선 수, 승패 여부

6.  전투 해결 (`_combat(atkId, defId)`):
    - 공격 데미지 = `max(100, floor(공격함선 × 진형공격력 × 지휘관보정 × 지형보정 × 난수(0.85~1.15) × 0.15 - 방어함선 × 진형방어력 × ... × 0.04))`
    - 반격 데미지 = `max(50, floor(방어함선 × 진형방어력 × ... × 0.06))`
    - 사기 저하 = `데미지 / 최대함선 × (50 or 25)`

#### 전술턴 종료 후 전략 복귀

7.  전술 전투 완료 후 `gameStore.applyBattleResult(result)` 호출:
    - **승리 시**:
      - 아군 함대 위치 = 목표 성계로 갱신
      - 적 함대 손실 분배
      - 목표 성계 점령 (faction 변경)
      - `game.addLog()`로 전투 결과 기록
    - **패배 시**:
      - 아군 함대 가장 가까운 아군 성계로 철수
      - 아군 함선 손실 적용
    - `_pendingBattle = null` → `GameView` 복귀 (`/game` 라우터 이동)
    - 다음 `_pendingBattle`이 있으면 반복, 없으면 `턴의 종료` 로직 수행
