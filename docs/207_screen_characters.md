```
├─────────────────────────────┤
```

## CharDetailModal.vue (세부 정보)

### 표시 항목

**능력치 한글 표기 (2열 배치)**
| 키 | 한글 | 키 | 한글 |
|---|---|---|---|
| CMD | 통솔 | MNG | 운영 |
| CSM | 지휘 | INF | 정보 |
| ATT | 공격 | GFG | 육전 |
| DEF | 방어 | AFG | 공전 |
| FST | 기동 | MMP | 정략 |

**성향 표기**
| 키 | 한글 | 비고 |
|---|---|---|
| brave  | 성격 | 수치(0~100)를 텍스트로 표시: 신중(0~19) / 냉정(20~39) / 일반(40~59) / 용맹(60~79) / 돌진(80~100) |
| moral  | 도덕 | 0~100, 바 + 수치 |
| friend | 친화 | 0~200, 바 + 수치 |
| idea   | 이념 | 0~200, 바 + 수치 |
| econ   | 경제 | 0~200, 바 + 수치 |

**전체 구성:**
```
프로필
  이미지 + 이름(한글/영문/일어)
  소속 세력 배지
  현재 직책/직업

능력치 (10개, 2열)
  통솔/지휘/공격/방어/기동
  운영/정보/육전/공전/정략

성향 (5개, 3열)
  성격(텍스트) / 도덕 / 친화 / 이념 / 경제

직업
  직업명 + 경험치 바 + 취득 턴

트레잇
  트레잇명 + 효과(한글) + 기간 (영구 / ~N턴)

소속 함대
  함대명 + 주둔 성계 + 역할(사령관/부관 등)
```

### 컴포넌트 props
```js
{
  chaCode: String,   // CHA_CODE
}
```

## 정보 공개 범위

### Phase A (현재 구현)
```
모든 인물 전체 정보 공개
아군/적군/중립 구분 없음
```

### Phase B (TODO)
```
INF 수치 기반 적군 정보 공개 범위 제한

INF 0~30:  이름 + 이미지만
INF 31~60: 기본 정보 + 통솔/지휘만
INF 61~90: 능력치 전체
INF 91~100: 능력치 + 성향 + 직업 + 트레잇 전체

적용 대상: 적군 / 중립 인물
아군 인물: 항상 전체 공개
```

## 호출 방식

```js
// CharModal 열기
game.openModal('char', { chaCode: 'CH_000064' })

// CharDetailModal 열기
game.openModal('charDetail', { chaCode: 'CH_000064' })

// GameView.vue MODAL_MAP 추가 필요
const MODAL_MAP = {
  ...
  char:       CharModal,
  charDetail: CharDetailModal,
}
```
