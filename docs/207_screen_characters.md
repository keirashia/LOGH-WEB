## CharacterInfoPopup.vue

### props

```js
{
  show:     Boolean,  // 표시 여부
  charCode: String,   // CH_XXXXXX 코드
  title:    String,   // 상단 타이틀 (선택, 직책명 등)
}
```

### 호출 방식

컴포넌트에 직접 마운트. `game.openModal` 방식이 아닌 인라인 사용.

```vue
<CharacterInfoPopup
  :show="!!hintPos"
  :char-code="hintPos?.charCode ?? null"
  :title="hintPos?.label ?? ''"
  @close="hintPos = null"
/>
```

현재 사용처: `MonarchyPostComp.vue`, `CouncilRingComp.vue` (홀드 제스처로 열림)

### 성향 표기

| 필드 | 표시명 | 방식 | 비고 |
|---|---|---|---|
| brave  | 성격 | 텍스트 레이블 | 신중/냉정/일반/용맹/돌진 |
| moral  | 도덕 | 바 + 수치 | 0~100 |
| friend | 친화 | 텍스트 레이블 + 힌트 | 플레이어와의 원형 거리 기반 |
| idea   | 이념 | 텍스트 레이블 | ideologyData.js 최근접 코드 |
| econ   | 경제 | 텍스트 레이블 | economyData.js 최근접 코드 |

성향 그리드: 3열 (`grid-template-columns: repeat(3, 1fr)`)

### 친화(friend) 힌트

친화 레이블 클릭(터치) 시 소형 힌트 박스가 레이블 하단에 표시됨.

```
┌──────────────┐
│ 친화도 계산   │
│ 내 친화   120 │
│ 상대 친화  85 │
│ 원형 거리  35 / 150 │
│ → 우호        │
└──────────────┘
```

- 힌트 외부 클릭 시 자동 닫힘 (`.cp-grid-3col @click`)
- 트리거: `.cp-hint-trigger` (점선 밑줄)

### 능력치 표기

10개 능력치를 2열 × 5행 column-flow 그리드로 표시.

| 좌열 | 우열 |
|---|---|
| 통솔 (statCmd) | 운영 (statMng) |
| 지휘 (statCsm) | 정보 (statInf) |
| 공격 (statAtt) | 육전 (statGfg) |
| 방어 (statDef) | 공전 (statAfg) |
| 기동 (statFst) | 정치 (statPlt) |

바 색상: `--tg` (gold, opacity 0.55). 수치 색상: valStyle() — 90%↑ gold / 70%↑ t1 / 50%↑ t2 / 나머지 td
